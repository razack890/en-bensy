# Samsaaram AI - 100% Free Cloud Deployment Guide 🌐

Samsaaram AI is built as a zero-dependency, lightning-fast static web app with Progressive Web App (PWA) support.
You can deploy it in less than **60 seconds for FREE** to get a permanent HTTPS link accessible worldwide on iPhone, Android, and PC!

---

## Option 1: Netlify Drop (Fastest - No Code / Drag & Drop - 30 Seconds) 🚀
1. Open [https://app.netlify.com/drop](https://app.netlify.com/drop) in your browser.
2. Sign up or log in for free.
3. Open Windows File Explorer and navigate to your Desktop: `C:\Users\bensy\Desktop\EN`
4. **Drag and drop the entire `EN` folder** directly into the Netlify Drop box in your browser!
5. In 15 seconds, Netlify generates a permanent, secure live HTTPS link (e.g. `https://samsaaram-ai.netlify.app`).
6. Open this link on your **iPhone Safari** or **Android Chrome**! The microphone, camera, and speech features will work 100% smoothly with HTTPS!

---

## Option 2: GitHub Pages (Free Permanent Hosting) 🐙
1. Create a free repository on [GitHub](https://github.com/new) named `samsaaram-ai`.
2. Push your project code:
   ```bash
   git init
   git add .
   git commit -m "Initial Samsaaram AI commit"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/samsaaram-ai.git
   git push -u origin main
   ```
3. In GitHub repo Settings ➔ **Pages**:
   - Source: Deploy from branch `main` / `root`.
4. Your free link will be live at: `https://YOUR_USERNAME.github.io/samsaaram-ai/`

---

## Option 3: Vercel (One Click Free) ▲
1. Install Vercel CLI or open [vercel.com](https://vercel.com).
2. Run in terminal:
   ```bash
   npx vercel
   ```
3. Follow the 3 prompts to deploy your site live with custom domain support.

---

## Mobile Installation (PWA on iPhone & Android) 📲
Once your site is live on HTTPS:
* **On iPhone**: Open the site in Safari ➔ Tap **Share (ചതുരവും അമ്പും ഉള്ള ഐക്കൺ)** ➔ Tap **"Add to Home Screen" (ഹോം സ്ക്രീനിലേക്ക് ചേർക്കുക)**.
* **On Android**: Open the site in Chrome ➔ Tap **"Install Samsaaram AI"** or the 3 dots ➔ **"Install app"**.
It will run just like a native mobile app with full offline support!
