# Samsaaram AI - Live English AI Teacher (സംസാരം AI) 🎙️👩‍🏫

> **Bilingual (Malayalam & English) Live AI Speaking Teacher** designed to help Malayalam speakers overcome hesitation, master real-world spoken English, and gain confidence in interviews, meetings, and daily life.

---

## ✨ Key Features

1. **🎙️ Live Human-like Voice & Audio**:
   - Talk naturally with **Teacher Maya (മായ മിസ്സ്)** using your microphone.
   - Real-time speech recognition tuned for Indian / Malayali English accents.
   - Natural audio speech output with **1.0x normal** and **0.75x slow repeat** options.
   - Glowing real-time audio waveform visualizer.

2. **🌴 Malayalam & Manglish Bilingual Mentorship**:
   - Every AI response features a clear **മലയാളം അർത്ഥം (Malayalam Meaning)** breakdown.
   - Ask or talk in **Malayalam or Manglish** (e.g. *"നാളെ വരാൻ പറ്റില്ല എന്ന് എങ്ങനെ ഇംഗ്ലീഷിൽ പറയും?"* or *"Enikku interviewinu engane introduce cheyyam?"*), and Maya explains the natural English expression.

3. **✨ Real-Time Grammar & Fluency Corrections**:
   - Catches common Malayali literal translation habits:
     - *"I reached yesterday only"* ➔ *"I arrived just yesterday."*
     - *"Myself Rahul"* ➔ *"I am Rahul / My name is Rahul."*
     - *"I have a doubt"* ➔ *"I have a question."*
     - *"He didn't came"* ➔ *"He didn't come."*

4. **💼 Real-World Practice Scenarios**:
   - **Friendly Chit-Chat (സൗഹൃദ സംഭാഷണം)**
   - **Job Interview (ജോബ് ഇന്റർവ്യൂ - IT / Gulf / General)**
   - **Office & Client Discussions (ഓഫീസ് മീറ്റിംഗ്)**
   - **Airport & Travel (എയർപോർട്ട് & യാത്ര)**
   - **Cafe, Restaurant & Shopping (ഷോപ്പിംഗ് & റെസ്റ്റോറന്റ്)**
   - **Malayalam to English Master (മലയാളം ➜ ഇംഗ്ലീഷ് തർജ്ജമ)**

5. **📞 Dual Experience Modes**:
   - **Classroom Chat Mode**: Step-by-step transcript with Malayalam cards and grammar tips.
   - **Live Voice Call Mode**: Immersive full-screen phone call simulation with Teacher Maya.

6. **⚡ Zero-Setup + Optional Gemini AI Integration**:
   - Works immediately out of the box with the built-in conversational AI tutor engine without any API keys!
   - Supports adding a **Google Gemini API Key** in settings (`⚙️`) for extended generative intelligence.

---

## 🚀 How to Run Locally

Run the local server with Python:

```bash
python server.py
```

Then open your browser at:
👉 **[http://localhost:8000](http://localhost:8000)**

*(Recommended Browsers for Web Speech Recognition: Google Chrome, Microsoft Edge, Brave).*

## 🌐 How to Make It Online (Free Hosting in 1 Minute)

Because this is built with clean, modern web standards (HTML5, CSS3, Vanilla JS):
